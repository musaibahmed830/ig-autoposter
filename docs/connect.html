Connect Instagram

← Dashboard

4 steps — token lo, account choose karo, long-lived banao, save karo. Sab kuch aapke browser mein hota hai; token kahin aur nahi jata.

1 Access token paste karo

Graph API Explorer kholo → apni app select karo → permissions: instagram_basic, instagram_content_publish, pages_show_list, business_management → Generate Access Token → yahan paste karo.

2 Apna Instagram account choose karo

Ye wo Business/Creator accounts hain jo aapke Facebook Pages se linked hain.

3 Long-lived token banao (60 din chalta hai)

App ID aur App Secret Meta app ke Settings → Basic se lo. Secret sirf isi browser mein use hota hai, kahin store nahi hota.

4 Save karo

Ye values GitHub repo → Settings → Secrets and variables → Actions mein daalo (naam bilkul same rakhna):

IG_USER_ID
IG_ACCESS_TOKEN

💡 Browser-save se dashboard par live account status + real-time followers dikhte hain — sirf isi device par. GitHub Secrets wala step automation ke liye zaroori hai, wo mat chhorna. Token ~50 din baad expire hoga; yahi wizard dobara chala lena.
