Connect Instagram

← Dashboard

3 steps — token lo, long-lived banao, save karo. Ye Instagram API with Instagram Login flow hai (koi Facebook Page linking nahi chahiye). Sab kuch aapke browser mein hota hai; token kahin aur nahi jata.

1 Access token paste karo

Meta Developer app → Instagram → API setup with Instagram login → permissions: instagram_business_basic, instagram_business_content_publish → Generate token → yahan paste karo. (Token IGAA… se start hota hai.)

2 Long-lived token banao (~60 din chalta hai)

Instagram App Secret Meta app ke Instagram → API setup with Instagram login page se lo. Ye is exchange ke liye chahiye, sirf isi browser mein use hota hai, kahin store nahi hota.

3 Save karo

Ye values GitHub repo → Settings → Secrets and variables → Actions mein daalo (naam bilkul same rakhna):

IG_USER_ID
IG_ACCESS_TOKEN

💡 Browser-save se dashboard par live account status + real-time followers dikhte hain — sirf isi device par. GitHub Secrets wala step automation ke liye zaroori hai, wo mat chhorna. Token ~60 din baad expire hoga; yahi wizard dobara chala ke naya token generate karna, phir refresh karna (grant_type=ig_refresh_token se, expire se pehle).
